# 🚀 KalamAI - AI-Powered Educational Web App for B.Tech (AKTU)

KalamAI is a full-stack, production-ready educational platform designed specifically for Dr. A.P.J. Abdul Kalam Technical University (AKTU) B.Tech students. It leverages **Google Gemini AI** to deliver instant, structured, and syllabus-aligned notes with real-life engineering examples.

---

## ✨ Features
* **Complete AKTU Syllabus Integration**: Structured unit-wise navigation and exam-focused prep.
* **AI Notes Generation**: Powered by Google Gemini AI (`gemini-2.5-flash`), generating clean headings, bullet points, and practical examples.
* **Secure Authentication**: Supports both custom Email/Password authentication and Google OAuth.
* **Premium Sunrise Orange UI**: Modern glassmorphism design with responsive navigation, interactive testimonials, and developer spotlight.

---

## 🛠️ Tech Stack
* **Frontend**: React.js, Tailwind/Custom CSS, Lucide Icons, React Markdown, Google OAuth.
* **Backend**: Node.js, Express.js, CORS, Google GenAI SDK.
* **Database**: MongoDB Atlas (Mongoose) / Local In-Memory Session Support.

---

## 🚀 Getting Started Locally

### 1. Clone the Repository
\`\`\`bash
git clone https://github.com/Maurya8960/kalamai.git
cd kalamai
\`\`\`

### 2. Setup Backend
\`\`\`bash
cd backend
npm install
# Create a .env file and add:
# PORT=8080
# FRONTEND_URL=http://localhost:3000
# GEMINI_API_KEY=your_gemini_api_key
node server.js
\`\`\`

### 3. Setup Frontend
\`\`\`bash
cd frontend
npm install
npm start
\`\`\`
